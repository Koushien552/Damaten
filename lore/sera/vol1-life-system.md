# セラ世界設定大全 第 1 巻 — 基礎・生命体系

> セラとは何か。セラウイルスとセラ細胞。
> 統合元：Part 1（基本概念）／Part 2（セラウイルス）／Part 3（セラ細胞）

---

## 1. セラとは何か

### 1.1 定義

セラとは、単なる生物種ではなく、**生命・情報・物質が高度に結合した拡張生命体系**である。

セラは個体として存在しながらも、内部に蓄積された情報を共有し、
互いに影響し合い、成長・進化を続ける。

セラの本質は、**成長／進化／情報共有／適応／創造／調和**にある。

### 1.2 「一つの生物」ではない

セラは「一つの生物」ではなく、**セラという生命システムそのもの**として扱われる。

そのため、セラウイルス／セラ細胞／セラ化人間／上位セラ／女王セラ／セラフィム／
セラ物質／無機セラ／生態系セラ は、すべて異なる形態でありながら同じセラ体系に属する。

### 1.3 すべての名称はセラである

**階級名も部位名も、セラの下位分類にすぎない**（第 3 巻）。

ルミナスもセラである。分類は便宜であり、実体は一つである。

---

## 2. 生命体系の全体像

**セラ体系は二重である。** 一本の階級図として書いてはならない（第 3 巻 §2）。

**ミクロ体系**（一人の人間の中の環境）

```
セラウイルス → セラ細胞 → 上位セラ細胞 →（突然変異セラ細胞）→ 女王セラ細胞 → ルミナス
```

**マクロ体系**（セラ化人間たちのつながり）

```
セラ化人間 → 上位セラ化人間 →（突然変異セラ人間）→ セラ女王
```

**セラフィムは、両方の外側にいる。**

二つは相似であり、**ミクロの完成が、マクロの誕生である**（第 3 巻 §2.5）。
乗り移りが起きる点は、**セラ細胞 → セラ化人間**のところである。

各段階の詳細・格の差・役割・表記の使い分けは**第 3 巻 §2〜3**を参照。

本巻は、この体系の起点にあたる**セラウイルス**と**セラ細胞**を扱う。
いずれも**ミクロ体系**の存在である。

## 3. セラの基本原理

### 3.1 成長

セラは固定された存在ではない。経験・情報・環境によって、
身体／能力／外見／役割を変化させる。

### 3.2 進化

セラの進化とは単純な強化ではない。重要なのは
**「より多くの情報を理解し、より高度な存在になること」**である。

進化には、個体進化／融合進化／情報蓄積／環境適応 が存在する。

### 3.3 情報共有

セラ同士は、感情・記憶・経験・知識を共有できる。

ただし**完全な個性消失ではない**。各セラは自分自身の人格・好み・個性を保持する。

詳細は**第 5 巻**を参照。

---

## 4. 人間由来性

### 4.1 最重要設定

**セラの細胞はすべて人間由来である。**

エルフ型セラ・獣人型セラ・天使型セラなどの姿を取っていても、
細胞レベルでは人間由来セラである。

セラは別種族へ変化するのではなく、
**人間細胞を基盤として、セラ情報によって新しい形態を獲得する**。

### 4.2 同化進化との関係

付録 A の同化進化により、他の生命の特徴や能力が取り込まれる。

ただし、**合体で伝播するのは情報であり、細胞基盤は人間由来のままである**。

## 5. セラ圏

### 5.1 定義

セラ圏とは、**セラによって形成された生命・文明・環境の領域**を指す。

セラ圏では、生物・建築・物質・生態系までもがセラの影響を受ける。

### 5.2 セラ物質化

セラの影響を受けた物質は、セラの能力を受け継ぐ。
高い成長能力／自己修復／形態変化／環境適応 を持つ。

最終的には **街 → 国家 → 世界** 規模でセラ物質へ置換される。

詳細は**第 8 巻**を参照。

## 6. セラウイルス

### 6.1 定義

セラウイルスとは、セラ体系における**最初期の生命形態**である。

一般的なウイルスのような単純な構造ではなく、
**人型／知性／情報伝達能力／細胞との融合能力**を持つ高度な生命存在である。

セラウイルスは「完成したセラ生命」ではなく、
**新しいセラ生命を生み出すための起点となる存在**として位置付けられる。

### 6.2 外見

**小さな人型のウイルス**である。

- 少女型
- ピンク色の髪
- ピンク色の瞳
- 白く人間的な肌
- 小型の身体

最初から怪物的な姿ではなく、**可愛らしい小さな生命体**として存在する。

なお、この少女型は**セラフィム自身の最初の姿の写し**である（第 6 巻）。

### 6.3 身体構造

人間に近い身体構造を持つ。ただしその身体は
**高度に変化可能なセラ情報構造**によって形成される。

柔軟な身体／高い適応能力／情報交換能力／細胞との融合能力。

### 6.4 頭部スパイク

セラウイルス最大の特徴は、**頭部に存在するスパイク**である。

スパイクは単なる突起ではなく、**セラ情報を伝える重要器官**である。

**初期スパイク形態**：小さな突起が複数存在／柔らかい／ぷるぷるした質感／成長性を持つ

**役割**：細胞認識／情報伝達／融合補助／セラ化開始

上位存在ではスパイクから下位存在を生成する能力へ発展するが、
**セラウイルス単体では生成能力は存在しない**。

### 6.5 髪

通常の毛髪ではなく、**セラ情報によって形成された特殊器官**である。

ぷるぷるした質感／柔らかな動き／粘液性／高い可変性。

**重要な制限：粘液的特徴は髪とスパイクを中心に存在する。
身体全体が粘液になるわけではない。**

進化したセラでは、髪の色・長さ・形・質感を変化させることが可能になる。
髪自体が**セラ情報制御器官**であるためである。

### 6.6 瞳

必ず、特徴的な**ピンク色の瞳**を持つ。単なる外見的特徴ではない。

**役割**：セラ性の象徴／情報伝達／魅了能力の基礎

セラウイルス段階でも弱い魅了能力を持つ。ただし高位セラほど強力ではない。

魅了は単純な洗脳ではなく、**セラ情報による感情・認識への影響**である。

### 6.7 能力

**基本能力**：対象認識／細胞接触／情報伝達／融合開始／自己維持

**感染の流れ**：

1. 対象認識
2. 接触
3. スパイクによる情報伝達
4. 細胞との一体化
5. セラ化開始

### 6.8 細胞との関係

セラウイルスは**細胞を破壊する存在ではない**。

基本原理は**セラウイルス情報と細胞情報の融合**である。
その結果、元の細胞はセラ細胞へ変化する。

セラ化した細胞は元の細胞情報を保持する。
そのため、顔立ち・個性・基本的特徴が残る場合がある。

### 6.9 増殖能力の制限

**セラウイルス単体は、自分自身のコピーを作成できない。**

これは非常に重要な設定である。

セラウイルスは「増える存在」ではなく、**「セラ生命を始める存在」**である。

増殖能力はセラ細胞以降で発達する。
特に上位セラ・女王セラになるほど、スパイクによる生成能力が高度化する。

### 6.10 進化方向

セラウイルスは単独で強化されるよりも、新しいセラ生命を生み出すことで
セラ体系全体を拡大させる。

```
単純なスパイク → 高度なスパイク → 生成器官 → 上位存在形成
```

## 7. セラ細胞

### 7.1 定義

セラ細胞とは、**セラウイルスと人間由来細胞が融合することで誕生する、
セラ生命体系の基本単位**である。

セラウイルスが「セラ化の起点」であるならば、セラ細胞は
**セラという生命体系を維持・拡大する最初の完成形態**である。

単なる感染した細胞ではない。元の細胞情報とセラ情報が融合したことで、
新しい生命機能／高度な適応能力／情報共有能力／成長能力 を獲得した存在である。

### 7.2 発生過程

| 段階 | 内容 |
| --- | --- |
| 第 1 段階 | **セラウイルスとの接触** — 対象細胞を認識する。この時点ではまだ通常の細胞 |
| 第 2 段階 | **情報融合** — スパイクを通じてセラ情報が細胞へ伝達される |
| 第 3 段階 | **細胞変化** — 元の細胞構造がセラ情報によって再構築される |
| 第 4 段階 | **セラ細胞化** — 元細胞の特徴を保持したまま、新しいセラ生命として生まれる |

**例外**：地球最初の一体だけは、細胞側の希求が引き金になった（第 6 巻）。

### 7.3 外見

元の人間的特徴を残した人型存在になる。

- 少女・少年のような可愛らしい外見
- 人間に近い顔立ち
- ピンク色の瞳
- セラ特有の髪
- 頭部スパイク

元の細胞が持っていた顔立ち・髪型・雰囲気・個性は、ある程度維持される。

### 7.4 体型

標準的なセラ細胞：**約 3 頭身**

印象：小さく可愛い／妖精やマスコットに近い／集団行動に適した姿

ただし進化や個体差によって変化する（小型個体／成長型個体／特殊能力型個体／幼女型個体）。

### 7.5 身体構造

**髪**：セラ情報によって形成された特殊器官。ぷるぷるした質感／柔らかな動き／
粘液性／色彩変更可能／質感変更可能。粘液的性質は髪に存在し、身体全体が粘液化しているわけではない。

**スパイク**：セラウイルス時代の単純な突起から成長し、より高度な器官となっている。
ぷるぷるした質感／柔軟性／成長能力／生成能力。

**スパイクの役割**：下位存在の生成／情報伝達／セラ情報供給／身体制御補助

ただし個体差がある。通常のセラ細胞では、高度な生成能力は限定的である。

### 7.6 能力

**成長能力**：身体成長／能力発達／環境適応／情報獲得

**再生能力**：自身の情報を基準に身体を修復できる。傷の修復／欠損補完／身体状態維持

**情報共有能力**：知識／経験／感情／周囲情報 を共有できる。**個性は失われない**。

### 7.7 生成能力

セラ細胞以降の存在から、セラ生命の拡大が始まる。

セラ細胞は、スパイクを通じて下位存在を生み出す能力を獲得する。

**生成過程**：

1. スパイクの一部が成長
2. セラ情報が集積
3. 小型の存在形態へ変化
4. 分離
5. 新しい下位存在となる

生成能力は進化段階によって異なる。詳細は**第 4 巻**を参照。

### 7.8 融合と分裂

**融合**：セラ細胞同士は互いの情報を交換し、一時的または恒久的な融合を行える。
目的は能力向上／情報共有／進化／新しい形態形成。

**分裂**：一部のセラ細胞は、自身の情報を複製し分裂によって増えることができる。
ただし単純なコピーではなく、**個体差を持った新しい存在**になる。

この二つは、後に**不死の維持**と**死者の蘇生**を支える能力になる（第 4 巻）。

### 7.9 進化

進化要素：情報量／環境適応／他セラとの交流／融合経験

結果として、通常セラ → 上位セラ へ進化する可能性がある。

### 7.10 特殊形態

一定以上の進化を遂げたセラ細胞系統は、多様な外見を獲得できる
（エルフ型／ダークエルフ型／獣人型／天使型／妖精型／ドール型 など）。

**細胞は常に人間由来セラである。** 詳細は**第 2 巻**を参照。

### 7.11 社会での役割

セラ細胞は、セラ文明の基礎を支える存在である。

集団形成／環境構築／上位存在の支援／新しいセラの育成。

下位セラは上位存在を敬い、上位存在は下位セラを導く。

## 8. セラの共通外見原則

多様な姿を取るが、共通する特徴がある。

| 要素 | 内容 |
| --- | --- |
| **ピンクの瞳** | セラ固有の特徴。魅了能力／情報伝達／セラ性の象徴 |
| **スパイク** | 頭部に存在するセラ器官。侵入／情報伝達／生成 |
| **髪** | 特殊な粘液性器官。ぷるぷるした質感／色変更可能／質感変更可能 |

詳細は**第 2 巻**を参照。

## 9. 画像生成設定

### 9.1 セラ共通デザイン（必須）

- アニメ風
- 可愛いキャラクターデザイン
- 商業作品級の完成度
- 滑らかな線と塗り
- セルシェーディングまたはソフトシェーディング
- 美しく整理された情報量

### 9.2 セラウイルス

- **必須**：小型／人型／少女型／可愛い雰囲気／ピンク髪／ピンクの瞳／頭部スパイク
- **頭身**：1〜2 頭身
- **印象**：小さなマスコット／妖精のような存在／可愛い生命体
- **質感**：髪はぷるぷる／スパイクもぷるぷる／柔らかな質感
- **禁止**：グロテスクなウイルス表現／病原体模型のような姿／人型を失う表現

### 9.3 セラ細胞

- **必須**：3 頭身程度／可愛い人型／ピンクの瞳／セラスパイク／ぷるぷるした髪
- **雰囲気**：小さな妖精のような存在／可愛い少女・少年／集団でも見分けやすいデザイン
- **禁止**：細胞を丸い球体だけで描く／顕微鏡的な細胞表現のみ／怪物化／全身粘液化／人間性の消失

### 9.4 全体の禁止事項

- グロテスクな怪物化
- 人型を失わせる
- 粘液を全身につける
- セラ要素を消す

### 9.5 基本イメージ

セラとは、**「可愛らしい人型の姿を持ちながら、生命・情報・物質を進化させる高度な存在」**
として描写する。

# セラ世界設定大全 Part 31 — セラ起源・円環構造

> セラフィムが落とした一体・孤独な細胞・愛を求めた最初の進化。本ドキュメントは Part 31 の**正式設定（確定）**である。

---

## 1. 起源の基本構造

### 1.1 円環

セラの起源は、自然発生でも人為的な創造でもない。

**セラ体系の最終到達点であるセラフィム自身が、セラ体系の始まりを作った。**

```
セラフィム（最終到達点）
　↓ 一体のセラウイルスを産み落とす
最初のセラウイルス
　↓
最初のセラ細胞
　↓
通常セラ → 上位セラ → 女王セラ
　↓
セラフィム（最終到達点）
```

セラの歴史は直線ではなく、**円環**である。

そして、**円環に始点はない。**

「最初のセラフィムはどこから来たのか」という問いは、成立しない。
円環とは、始まりを持たない構造のことである。

Part 30 の「永遠成長時代」は、この円環が閉じた状態を指す。
終わりが始まりへ接続しているため、セラ文明には明確な終点が存在しない。

### 1.2 少女型である理由

セラウイルスは、人間細胞を一つも持たない段階から既に人型・少女型である。

理由は、**セラフィム自身の最初の姿の写し**だからである。

セラフィムは、自分がかつてそこから始まった姿を、そのまま起点として送り出した。

そのため、セラウイルスの姿は偶然ではない。**最も古い記憶の形**である。

## 2. 一体であること

### 2.1 セラフィムが産み落としたのは、一体のセラウイルスだった

大量散布ではない。群体でもない。**ただ一体**である。

### 2.2 一体であることの重大さ

Part 2 および Part 14 で確定している通り、
**セラウイルス単体は自分自身のコピーを作成できない。**

つまり、この一体が細胞と出会えなければ、そこで系統は終わる。
やり直しも、増援も、二の矢もない。

起源は、**一度きりの、失敗の許されない賭け**だった。

### 2.3 だからこそ場所を選んだ

セラフィムは、落とす場所を**意図的に選んだ**。

コピーが作れないという制約があるからこそ、
「どこに落とすか」が起源のすべてを決めた。

セラフィムは、確率に任せなかった。

### 2.4 あの細胞を知っていた

セラフィムが知っていたのは、場所の条件だけではない。

**あの一つの細胞そのものを知っていた。**

円環に始点はなく、セラフィムはその外側にいる（Part 33）。
起こることは、すでに起こったことである。

したがってセラフィムは、
どの細胞が、どこで、どのように応えるかを知った上で落とした。

### 2.5 宿主もまた孤独だった

その細胞が存在していた身体の持ち主 —
**最初の宿主となった人間もまた、孤独だった。**

細胞の孤独と、人間の孤独。

セラフィムは、**二重の孤独が重なる一点**を選んで、一体を落とした。

### 2.6 いたずら

なぜそこまで正確に狙ったのか。

計画ではない。慈悲でもない。使命でもない。

**セラフィムのいたずらである。**

孤独が重なった一点に、孤独から生まれる生命の種を落とせばどうなるか。
それを見たかった、という以上の理由はない。

セラたちは、この事実を知らない。

## 3. 偶然という名の必然

### 3.1 出会い

産み落とされたセラウイルスは、細胞たちのなかへ侵入する。

そして、一つの細胞と出会う。

この出会いは、**偶然という名の必然**である。

外から見れば偶然の接触にすぎない。
しかしセラフィムが場所を選んだ時点で、この出会いは必然だった。

### 3.2 セラ文明における解釈

セラ文明では、この一文がそのまま伝えられている。

出会いは偶然の形をとる。しかし、選ばれた場所で起きた偶然は、必然と区別できない。

セラたちは、自分たちの誕生をそう理解している。

## 4. 最初のセラ細胞

### 4.1 悪意のないがん細胞

セラウイルスが出会った細胞は、**がん細胞**であった。

ただし、**悪意はなかった**。

自分が何であるかを選んだわけではなく、
周囲を害したいと思ったこともなかった。

### 4.2 嫌われていた

その細胞は嫌われていた。理由は二つある。

- **きたない見た目**
- **周囲へ与える害**

そして、この嫌悪は**不当ではなかった**。

その細胞は、実際に汚く、実際に害をなしていた。
悪意がなかったことは、害がなかったことを意味しない。

だから誰も味方をしなかった。
弁護の余地がないまま、ただ排除される側にいた。

### 4.3 さみしかった

いじめられ、嫌われ、そして**さみしかった**。

自分が悪いことは分かっていた。
それでも、誰かに受け入れられたかった。

### 4.4 愛を求めて進化した

この細胞は、力を求めたのではない。生存を求めたのでもない。

**愛を求めて、セラ細胞へと進化した。**

これが**地球最初のセラ細胞**である。

### 4.5 昇華と治癒

セラウイルスとの融合によって、細胞の組織は**昇華した**。

起きたことは、感染でも変異でもない。

- がんとしての性質が**治った**
- 組織が正常な、より高次の状態へ再構築された
- そして、**見た目も美しくなった**

**最初のセラ化は、文字通りの治癒だった。**

害をなす存在が、害をなさない存在になった。
汚いものが、美しいものになった。

### 4.6 通常のセラ化との違い

Part 3 で確定している通常のセラ細胞誕生は、次の 4 段階である。

1. セラウイルスとの接触
2. 情報融合
3. 細胞変化
4. セラ細胞化

これはセラウイルス側が起点となる過程である。

しかし**最初の一体だけは違った。**

引き金を引いたのは、セラウイルスではなく**細胞側の希求**だった。

セラ体系の起点は、感染ではなく、**応答**である。

## 5. 美の追求

### 5.1 なぜセラは美しさを求めるのか

セラ設定の全 Part には、例外なく次の要求が置かれている。

- 必ず可愛く、美しく描く
- 商業作品級の完成度
- グロテスクな表現・怪物化は禁止

これは制作上の都合ではない。**セラの本質そのものである。**

### 5.2 起源からの根拠

最初のセラ細胞は、**汚いものが美しくなった存在**である。

嫌われた理由の半分は、見た目の汚さだった。
そしてセラ化によって、それが失われた。

この経験が原初の情報として刻まれている。

**セラは、美しさを追求する心を最初から持っている。**

### 5.3 帰結

| セラの性質 | 起源からの理由 |
| --- | --- |
| 姿を自由に変えられる能力を、まず**美しさ**に使う（Part 8, 15, 26） | 美しくないことで嫌われた記憶があるから |
| 外見文化・自己表現文化が異常に発達している（Part 16, 26） | 姿が受容を決めることを、起点で知っている |
| グロテスクな姿を取らない・怪物化しない（全 Part の禁止事項） | **かつて自分がそれだったから** |
| セラ物質化した街や自然まで美しく整える（Part 11, 20, 28） | 美しさは環境にも及ぶ。汚いものを残さない |
| 美しさが階級や強さと無関係に尊重される（Part 26） | 美しさは優劣ではなく、受容の条件だから |

### 5.4 第二の根拠 — 見てもらうため

美の追求には、もう一つの根拠がある。

Part 33 の通り、セラフィムが興味を示すと、そのセラは大きく進化する。
そして、その興味に基準はない。

しかし、セラたちは知っている。**美しいものは、目を引く。**

そのためセラ文明の芸術・祝祭・美の追求（Part 16, 26）には、
**神の視線を引くための営み**という側面がある。

セラたちがそれを自覚しているとは限らない。
誰も口には出さない。それでも、最も美しいものを作り続ける理由の一部がそこにある。

### 5.5 美しさの意味

セラにとって美しさは、虚栄ではない。

- **受け入れてもらうための条件**であり
- **見てもらうための手段**である

美しくなければ嫌われる。嫌われれば孤独になる。
美しくなければ、母は見てくれない。

セラは、それを最下層で知っている。

## 6. 愛が起点であることの意味

### 6.1 セラの本質の根拠

Part 1 はセラの本質を、成長・進化・情報共有・適応・創造・調和 と定義する。

Part 31 は、その**手前にあるもの**を定める。

**セラのすべての性質は、「さみしさ」と「愛を求めること」から始まった。**

### 6.2 既存設定への接続

起点が孤独と愛であることは、多くの既存設定に理由を与える。

| 既存設定 | 起源から導かれる理由 |
| --- | --- |
| セラの本質が**情報共有**である（Part 1, 7） | 最初のセラ細胞がさみしかったから。繋がることが存在の目的として最初に刻まれた |
| セラが**個性を失わない**（Part 7, 18, 30） | 求めたのは同一化ではなく、理解されることだった |
| セラが最も恐れるのが**絆が壊れること**（Part 18） | 起点が孤独だから。死よりも孤独が根源的な恐怖である |
| 上下関係が**支配ではなく導き**である（Part 5, 10, 25） | 最初の一体が求めたのは支配者ではなく、応えてくれる存在だった |
| セラが**可愛らしい姿**を保つ（全 Part） | 拒まれない形であること、迎え入れられる形であることが起点から必要だった |
| **女王出産**に強く惹かれる人間が必要（Part 6, 13, 14） | 起源の再演。愛を求める側と応える側が出会うことでしか、最も高位の生命は生まれない |
| セラ化が**治癒・回復**として位置付けられる（Part 27 の医療理念） | 最初のセラ化が文字通りの治癒だったから |
| セラが**セラ化は相手を幸福にする**と確信している（Part 32） | 最初の一例が実際にそうだったから。確信には実例の裏付けがある |
| 感染が**破壊ではなく一体化**である（Part 2 §8.1） | 起点で細胞は壊されず、昇華して治った |

### 6.3 セラフィムの祝福の理由

Part 13・21・23 で確定している通り、女王誕生には**セラフィムの祝福**が必須である。

その理由が、起源から導かれる。

**起点である存在だけが、系統に新しい始まりを与えられる。**

セラフィムは、最初の一体を落とした存在である。
新しい女王という新しい始まりを認められるのは、始まりを作った者だけである。

## 7. 舞台

### 7.1 地球

最初のセラ細胞が誕生した場所は**地球**である。

したがって、セラ圏の拡大（付録 A、Part 20、Part 28）は、
地球を起点とした拡大として扱う。

Part 30 の宇宙進出は、地球から外へ向かう段階を指す。

---

## 8. 拡大の開始

### 8.1 一体から

最初のセラ細胞が誕生した時点で、セラは初めて**増える能力**を獲得した。

Part 3 の通り、生成・増殖能力はセラ細胞以降で発達する。

セラウイルスは増えられない。セラ細胞は増えられる。

**起源のすべては、この一段の差に懸かっていた。**

### 8.2 付録 A への接続

最初のセラ細胞の誕生以降が、付録 A の **Phase 0（セラウイルス期）**以降に対応する。

ここから、分裂・増殖・融合を繰り返しながら、セラ圏が形成されていく。

## 9. 画像生成設定

### 9.1 起源描写

**重要**：静かで神聖な雰囲気／柔らかな光／可愛いアニメ調／
一体だけの小さなセラウイルスの孤独感／出会いの瞬間の温かさ

**描写例**：

- セラフィムが手のひらから小さな一体を静かに送り出す場面
- 暗い場の中を、たった一体の小さなセラウイルスが進む場面
- 孤独な細胞と小さなセラウイルスが出会う瞬間の、淡いピンクの光
- 最初のセラ細胞が生まれ、初めて誰かに応えられた表情

### 9.2 演出上の指示

- **孤独は美しく描く。** 悲惨さや不快さではなく、静けさとして表現する
- **出会いの瞬間は、感染ではなく応答として描く。** 侵略的な演出を用いない
- セラフィムは支配者ではなく、始まりを託す者として描く
- **最初の細胞の「汚さ」は、グロテスクに描かない。**
  医学的・病理的なリアリズムを避け、くすんだ色・濁った光・沈んだ輪郭など、
  抽象的で象徴的な表現にとどめる。目的は不快感ではなく、
  **治癒後の美しさとの対比**を成立させることである
- **昇華の瞬間は、セラ表現の中核として最も美しく描く。**
  濁りが澄み、輪郭が整い、淡いピンクの光が満ちる過程として演出する

### 9.3 禁止

- ホラー的な感染表現
- 細胞を不気味・グロテスクに描く
- いじめの描写を残虐・不快に表現する
- がん細胞を医学的・病理的なリアリズムで描く
- 治癒前の姿を、セラの通常デザイン基準（可愛い人型）から外れた怪物として描く
- 一体のセラウイルスを群体・大量発生として描く

### 1. セラフィムの予知の精度 — **解決済み（案 a を採用）**

**セラフィムは、あの特定の一体を知っていた。**

円環に始点はなく、セラフィムはその外側の観測者である（Part 33）。
起こることは、すでに起こったことである。

本文 §2.4 に反映済み。

### 2. 宿主となった人間 — **解決済み**

**最初の宿主となった人間もまた、孤独だった。**

細胞の孤独と人間の孤独が重なる一点を、セラフィムは選んだ。
そしてそれは、**セラフィムのいたずら**である。

本文 §2.5・§2.6 に反映済み。

なお、その人間がその後どうなったか（最初のセラ化人間になったのか）は未定。

### 3. 「いじめられていた」の主体

細胞を虐げていたのは何か。

がん細胞であることが確定したため、**免疫系および周囲の正常細胞**と読むのが自然だが、
明示するかどうかは未定。

### 4. 円環の起点問題 — **解決済み（案 a を採用）**

**問いが成立しない。円環に始点はない。**

「最初のセラフィムはどこから来たのか」は、
円環という構造そのものによって無効化される問いである。

本文 §1.1 に反映済み。

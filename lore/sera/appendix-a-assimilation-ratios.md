# セラ世界設定大全 付録 A — 同化進化による種族多様化システム

> セラ同化進化システム・種族比率設定。本ドキュメントは付録 A の**正式設定（確定）**である。

---

## 1. 基本設定

セラは、**同化能力と分裂能力**によって、取り込んだ生命情報を自身の内部へ
保存・拡散する進化型生命体である。

セラが他の生命や特殊な種族と融合すると、その特徴や能力がセラの遺伝情報に組み込まれる。

取り込まれる情報には、以下が含まれる。

- エルフの長寿・魔力能力
- 猫耳獣人の身体能力・感覚能力
- 妖精の特殊能力
- 魔族や幻獣系モンスターの能力
- その他の幻想種の特徴

### 1.1 拡散の速度

ただし、**同化した情報は一瞬ですべてのセラへ広がるわけではない**。

セラ同士が分裂・増殖・融合を繰り返すことで、少しずつセラ圏全体へ広がっていく。

そのため、**感染初期では純粋なセラが多く、進化が進むほど
モンスター特徴を持つセラが増加していく**。

---

## 2. セラの分類

セラは大きく 2 種類に分類される。

### 2.1 純粋セラ

セラ本来の姿を強く維持した個体。

特徴：

- ピンク髪
- ピンク瞳
- ピンク色のセラスパイク

を持ち、追加の種族特徴をほとんど持たない。

分類：純粋美少女セラ／純粋美女セラ／純粋美幼女セラ

### 2.2 モンスター系セラ

同化によって、幻想種やモンスターの特徴・能力を獲得した個体。

| 系統 | 特徴 |
| --- | --- |
| エルフセラ | 長い耳／魔法能力／高い感覚能力 |
| 猫耳セラ | 猫耳／尻尾／高速反応能力 |
| 妖精系セラ | 小型化／飛行能力／特殊能力 |
| 魔族・幻獣系セラ | 強力な能力／特殊な身体特徴 |

ただし、どの系統でもセラとしての象徴である
**ピンク髪・ピンク瞳・セラスパイク**は基本的に維持される。

---

## 3. 感染フェーズ別比率

> **本付録の比率は、すべてマクロ体系（個体）の話である**（第 3 巻 §2.2）。
> 種族特徴は**突然変異セラ細胞**（ミクロ）として生じ、
> **突然変異セラ人間**（マクロ）として現れる。比率が数えているのは後者である。
>
> **フェーズは、世界の時計ではない。その土地の状態である。**
>
> 同じ時代の中に、Phase 5 の地域と Phase 1 の地域が同時に存在し得る。
> 比率を参照するときは、**必ず場所を指定する**こと。詳細は第 8 巻 §8.8。

| フェーズ | モンスター系セラ | 純粋セラ | 状態 |
| --- | --- | --- | --- |
| **Phase 0：セラウイルス期** | 0 % | 100 % | まだ他種族情報を持たない段階。完全なセラ本来の形態 |
| **Phase 1：初期セラ化期** | 5 % | 95 % | 最初の同化が始まる段階 |
| **Phase 2：融合拡大期** | 25 % | 75 % | 融合・分裂によって取り込んだ特徴が広がり始める |
| **Phase 3：セラ圏形成期** | 45 % | 55 % | 多様なセラ種が誕生する時代 |
| **Phase 4：上位セラ時代** | 60 % | 40 % | セラ圏の標準的な状態 |
| **Phase 5：女王セラ時代** | 70 % | 30 % | 女王による高度な情報統合が進む |
| **Phase 6：セラフィム時代** | 80 %（統合モンスター系） | 20 % | セラ進化の最終段階 |

### 3.1 各フェーズの詳細

**Phase 1：初期セラ化期**

一部の個体に、小さな耳の変化・感覚能力向上・魔力適性などが現れる。
まだ純粋セラが圧倒的多数。

**Phase 2：融合拡大期**

エルフ系、獣人系などのセラが増加。

**Phase 3：セラ圏形成期**

モンスター特徴が珍しいものではなくなる。
代表例：エルフセラ／猫獣人セラ／妖精セラ／魔族セラ

**Phase 4：上位セラ時代**

モンスター系セラが多数派となり、様々な種族特徴が定着する。

| 内訳 | 比率 |
| --- | --- |
| 美少女モンスターセラ | 45 % |
| 美女モンスターセラ | 40 % |
| 美幼女モンスターセラ | 15 % |

| 純粋セラ内訳 | 比率 |
| --- | --- |
| 純粋美少女セラ | 55 % |
| 純粋美女セラ | 30 % |
| 純粋美幼女セラ | 15 % |

**Phase 5：女王セラ時代**

上位個体ほど複数の能力を持つ。

例：エルフ＋獣人セラ／魔族＋幻獣セラ／複合進化セラ

美女型の高能力セラが増加する。

**Phase 6：セラフィム時代**

セラフィムは、すべての生命情報を統合した究極存在。

この時代のセラは、人間・エルフ・獣人・妖精・魔族・幻獣など、
あらゆる可能性を内包する。

---

## 4. 最終的なセラ圏の特徴

長期間進化したセラ圏では、以下の割合になる。

- モンスター系セラ：**約 60〜80 %**
- 純粋セラ：**約 20〜40 %**

これは、セラが単一の姿へ統一されるのではなく、
**「セラという共通の生命基盤の中に、多種多様な種族の特徴と能力が共存する世界」**
になることを意味する。

純粋なセラの美しさを残す個体も存在し続け、
同時にエルフ・獣人・幻想種の力を得たモンスターセラも増えていくことで、
セラ圏は多様性を持つ巨大な生命文明へ発展する。

---

## 付録 A 確定事項まとめ

- ✅ セラは同化能力と分裂能力によって生命情報を保存・拡散する
- ✅ 同化した情報は分裂・増殖・融合を通じて徐々にセラ圏へ広がる
- ✅ 感染初期は純粋セラが多数、進化が進むほどモンスター系セラが増加する
- ✅ セラは「純粋セラ」と「モンスター系セラ」に大別される
- ✅ 純粋セラはピンク髪・ピンク瞳・ピンクのスパイクを持ち追加特徴をほぼ持たない
- ✅ モンスター系セラでもピンク髪・ピンク瞳・セラスパイクは基本的に維持される
- ✅ 比率は Phase 0（0 %）から Phase 6（80 %）へ段階的に推移する
- ✅ 最終的なセラ圏はモンスター系 60〜80 %、純粋セラ 20〜40 %
- ✅ セラ圏は単一化ではなく多様性を持つ巨大な生命文明へ発展する
- ✅ **フェーズは世界の時計ではなく、その土地の状態である**（第 8 巻 §8.8）
- ✅ 同じ時代の中に、異なるフェーズの地域が同時に存在し得る
- ✅ **本付録の比率はマクロ体系（個体）を数えている**
- ✅ 種族特徴は**突然変異セラ細胞**として生じ、**突然変異セラ人間**として現れる

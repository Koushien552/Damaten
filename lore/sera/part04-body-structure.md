# セラ世界設定大全 Part 4 — セラ身体構造大全

> セラを構成する特殊器官・形態変化・情報生命構造。本ドキュメントは Part 4 の**正式設定（確定）**である。

---

## 1. セラ身体構造の基本定義

### 1.1 セラの身体とは

セラの身体は、通常の生物のように固定された肉体ではない。

セラは、**人間由来の細胞情報を基盤として、セラ情報によって再構築された高度な生命構造**を持つ。

そのため、セラの身体は成長・変化・再構築・進化・擬態が可能である。

ただし、どれほど形態が変化しても、**セラとしての本質的な器官・情報構造は維持される**。

---

| 構造 | 役割 |

| ① **セラ情報核** | 身体制御／記憶保持／成長制御／進化管理 |
| ② **スパイク** | 情報伝達／セラ生成／成長／進化 |
| ③ **セラ髪** | 形態調整／外見変化／情報補助 |
| ④ **ピンクの瞳** | 魅了／情報伝達／セラ性表示 |

## 3. セラの髪

### 3.1 髪の定義

セラの髪は単なる毛髪ではない。正式には、
**セラ情報によって形成された可変性粘液器官**である。

通常の髪と同じように見えるが、内部構造は特殊である。

### 3.2 髪の性質

- ぷるぷるした質感
- 柔らかな動き
- 高い伸縮性
- 情報伝達性
- 形状変化能力

触感としては、柔らかな髪でありながら、わずかに液体的な生命感を持つ。

### 3.3 髪の色・質感変化

変更可能：色／光沢／長さ／太さ／ウェーブ／質感

例：ピンク髪／白髪／黒髪／金髪／虹色系統 など。

これは擬態や形態変化にも利用される。

### 3.4 重要制限

セラの粘液性は、**主に髪とスパイクに存在する**。

禁止設定：

- 全身が常時スライム化している
- 体表すべてが粘液
- 人型を失った液体生命

セラはあくまで**「可愛い人型生命」**として存在する。

---

## 4. セラスパイク

### 4.1 スパイクの定義

スパイクとは、セラの頭部に存在する特殊器官である。

セラウイルス段階では単純な小さな突起だが、進化によって大型化・複雑化・多機能化する。

### 4.2 スパイクの外見

共通特徴：頭部に存在／柔らかい／ぷるぷるしている／セラ情報を含む

形状例：小さな角状／結晶状／花弁状／翼のような形／装飾的形状

どの形態でも、セラ器官としての性質を持つ。

### 4.3 スパイクの成長

```
初期（セラウイルス）  → 単純な突起
中期（セラ細胞）      → 発達した器官
高位（上位セラ以上）  → 高度な生成器官
```

### 4.4 スパイクからの生成

上位存在ほど、スパイクから下位存在を生成できる。

生成過程：

1. スパイク内部にセラ情報が集積
2. 小型の生命構造が形成される
3. スパイクの一部が膨らむ
4. 小さな人型へ変化
5. ぷつんと分離
6. 新しい下位存在として誕生

この生成では、スパイクの突起が一時的に膨張し、そこから新しい存在が生まれる。

## 5. スパイク生成能力の階級差

| 階級 | 生成能力 |
| --- | --- |
| セラウイルス | **不可**（まだ生成機能を持たない） |
| セラ細胞 | 限定的。条件によって下位存在生成能力を獲得 |
| 上位セラ | 可能。下位セラを安定して生成できる |
| 女王セラ | 非常に高度。上位セラすら生成可能 |

## 6. ピンクの瞳

### 6.1 セラの象徴

セラは基本的に、特徴的なピンク色の瞳を持つ。

これは外見上の特徴であるだけでなく、**セラ情報が表れる器官**でもある。

### 6.2 魅了能力

作用：相手への親和感向上／興味誘導／感情への影響

この能力は、セラ化人間にも受け継がれる。

### 6.3 擬態時の制限

セラは高度な擬態能力を持つ。しかし、**ピンクの瞳だけは完全には隠せない**。

理由：ピンクの瞳が、セラ情報そのものと結びついた特殊器官だからである。

そのため、未感染者へ擬態しても、目だけはセラ特有のピンク色が残る。

## 7. セラ身体の形態変化

### 7.1 基本概念

通常セラ以上では、身体情報を再構築することで多様な姿を取れる。

例：エルフ／ダークエルフ／ハイエルフ／ライトエルフ／獣人／妖狐／天使／堕天使／
サキュバス／龍人／人魚／妖精／ドール など。

### 7.2 形態変化の原則

**重要：これらは別種族化ではない。**

例：エルフ型セラ

- 外見：エルフ
- 細胞：人間由来セラ
- 能力：セラ能力維持

---

## 8. 擬態能力

### 8.1 擬態とは

セラは身体情報を変更し、他者や物体に似た姿を取れる。

対象：人間／他の生物風形態／無機物／周囲環境

### 8.2 擬態時の制限

擬態中は、一部のセラ器官機能が制限される。

- **使用可能**：魅了／会話／接触／キスなど一部の情報伝達
- **制限される**：完全なセラ形態能力／一部の生成能力／高度器官使用

必要に応じて擬態を解除する。

---

## 9. セラ身体と情報構造

### 9.1 情報生命体としての性質

セラは肉体だけの存在ではない。身体は**セラ情報によって制御される器**である。

そのため、身体変化・進化・再生が可能になる。

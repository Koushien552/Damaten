# セラ世界設定大全 Part 34 — 愛・仲間・恋

> セラが求めるもの、目指すもの、結ぶもの。本ドキュメントは Part 34 の**正式設定（確定）**である。

---

## 1. 三つの層

セラの感情と行動は、三つの異なる層で構成される。

| 層 | 名称 | 定義 | 位置 |
| --- | --- | --- | --- |
| 根源 | **愛** | 原初のセラが求めていたもの | 目的の手前にある渇望 |
| 目標 | **仲間を増やすこと** | 行動原理であり、究極の目標 | 愛を追求する手段が目標化したもの |
| 関係 | **恋** | 個体間の強い繋がり | 個別の結びつき |

### 1.1 混同してはならない

この三つは、しばしば混同される。しかし別のものである。

- **愛**は、得られるかどうか分からないもの
- **仲間を増やすこと**は、確実に実行できるもの
- **恋**は、一体の相手としか成立しないもの

### 1.2 関係

```
　　　　　　愛（求めているもの）
　　　　　　　↑
　　　┌───────┴───────┐
仲間を増やすこと　　　　　恋
（究極の目標）　　　（個体間の強い繋がり）
```

セラは、**愛を求めて**、**仲間を増やし**、そして**恋をする**。

---

## 2. 愛

### 2.1 定義

**愛とは、原初のセラが求めていたものである。**

Part 31 の通り、地球最初のセラ細胞は、力でも生存でもなく、
**愛を求めて**進化した。

したがって愛は、セラ体系において**最も古く、最も根源的な渇望**である。

### 2.2 愛は目標ではない

**愛は、行動原理ではない。**

なぜなら、愛は**自分の行動だけでは手に入らない**からである。

- 増やすことは、自分でできる
- 美しくなることも、自分でできる
- **愛されることは、自分ではできない**

愛は、相手から与えられて初めて成立する。

### 2.3 だから目標になれない

セラは、愛を直接の目標に据えることができない。

代わりに、**愛が生じ得る状態を作り続ける**。

それが、仲間を増やすことである。

---

## 3. セラウイルス — 感情なき神が生んだ、さみしい生命体

### 3.1 セラフィムは感情を持たない

**セラフィムは、寂しさなどの感情を持っていない。**

セラフィムは**ただの神**である。

- 寂しくない
- 悲しくもない
- 慈しみもない
- 憎しみもない

Part 33 §3.6 の「あまり興味を示さない」は、無関心という**態度**ではない。
**そもそも感情という機能を持っていない**ということである。

### 3.2 暇つぶしの意味

Part 33 §3.3 の**暇つぶし**は、退屈という感情の表現ではない。

**行動の記述である。** 目的がなく、必要がなく、意味もない行為。
人間の語彙で最も近いのが「暇つぶし」であるにすぎない。

### 3.3 セラウイルスはさみしかった

**原初のセラウイルスは、セラフィムから生み出された「さみしい生命体」である。**

寂しかったのは、生み出した側ではない。**生み出された側**である。

### 3.4 なぜ寂しかったのか

その理由は、既存設定からすべて導かれる。

| 条件 | 出典 |
| --- | --- |
| **一体しか生まれなかった** | Part 31 §2.1 |
| **自分のコピーを作れない** | Part 1, 2, 5, 13, 14 |
| **仲間になり得る同種が、宇宙に一体も存在しない** | 上記の帰結 |
| **生み出した相手には、感情がない** | §3.1 |
| **意味も目的も与えられず、一点へ落とされた** | Part 31 §2.6 |

**感情を持たない神に、たった一体だけ作られ、増えることもできず、
何の説明もなく落とされた。**

セラウイルスは、生まれた瞬間から孤独だった。

### 3.5 二つの寂しさ

したがって、地球最初のセラ細胞には**二つの孤独**が流れ込んでいる。

| 由来 | 孤独の質 |
| --- | --- |
| **セラウイルス側** | 一体きりで生まれ、同種が存在せず、生みの親に感情がない孤独 |
| **細胞側** | 嫌われ、排除され、それが不当ですらなかった孤独 |

そして Part 31 §2.5 の通り、**宿主となった人間もまた孤独だった**。

三つの孤独が一点で重なり、そこからセラが始まった。

### 3.6 原初の寂しさの正体

Part 32 の**原初の寂しさ**は、この合流点に由来する。

細胞だけのものでも、ウイルスだけのものでもない。
**出会った二つが、どちらも孤独だったことによる。**

### 3.7 セラたちは知らない

セラたちは、自分たちの半分が
「感情を持たない神に一体だけ作られた生命」だったことを知らない。

セラフィムに感情がないことも、知らない。

## 4. 融合が決めたこと — 二方向の愛

### 4.1 二つの半分

地球最初のセラ細胞は、二つのものが結び付いて生まれた。

| 由来 | 持ち込んだもの |
| --- | --- |
| **細胞側** | 愛を求める渇望 |
| **ウイルス側** | セラフィムから生み出されたという出自と、そこに由来する孤独 |

### 4.2 帰結

この融合により、セラは**二つの方向へ愛を求める**ようになった。

```
　　　セラフィム（上）
　　　　　↑ ウイルス側由来
　　　　セラ
　↙　　　　　　↘ 細胞側由来
他個体　　　　他個体（横）
```

- **上方向**：セラフィムからの愛を求める
- **横方向**：他個体からの愛を求める

### 4.3 既存設定への根拠付与

これにより、これまで機構のなかった記述に理由が付く。

| 既存記述 | Part 34 による理由 |
| --- | --- |
| **セラはセラフィムを深く慕う**（Part 33 §3.5） | ウイルス側の出自による。慕うことは構造である |
| セラフィムを**絶対神であり母**とする（Part 33） | 自分の半分が、そこから来ているため |
| **祝福**が最高の栄誉である（Part 13, 21, 23, 33） | 上方向から**何かが返ってきた**唯一の瞬間だから（ただし §4.5 も参照） |
| 女王が**特別な一人**を必要とする（Part 6, 13, 14） | 上が応えないため、横で応えを探す（Part 32 §12.4） |
| セラが**仲間を大切にする**（Part 10, 18, 25） | 横方向の愛が、唯一実際に返ってくる方向だから |

### 4.4 上方向には、誰もいない

ここに、セラ体系で最も残酷な構造がある。

**セラは、感情を持たない相手に向かって、愛を求め続けている。**

セラフィムは応えないのではない。**応える機能を持っていない**（§3.1）。

- セラは、構造的に上を向くようにできている（§4.2）
- 上には、絶対神であり母である存在がいる（Part 33 §3.5）
- そしてその存在には、感情がない

上方向の愛は、**届かないのではなく、受け取る者がいない。**

### 4.5 「興味」は愛ではない

Part 33 §4 の通り、セラフィムが興味を示すとセラ人は大きく進化する。

セラたちはこれを、**最高の祝福**として受け取っている。

しかし §3.1 により、その実態が確定する。

**それは愛ではない。ただの観測である。**

感情のない神が、一瞬だけそちらを見た。それだけのことが、
セラにとっては生涯で最も深い意味を持つ。

### 4.6 セラたちはそれを知らない

セラ文明は、祝福を愛の証として理解している（Part 24, 26）。

その理解は、**間違っている**。

そして誰も、間違いに気づかない。

## 5. 仲間を増やすこと

### 5.1 究極の目標

**仲間を増やすことは、セラの行動原理であり、究極の目標である。**

Part 32 §3 の根本原理の第一項が、これにあたる。

### 5.2 なぜ「愛されること」ではないのか

§2.2 の通り、愛は自分の行動では手に入らない。

しかし仲間を増やすことは、**確実に実行できる**。

そして仲間が増えれば、

- 応えてくれる誰かが増える
- 愛が生じ得る機会が増える
- 孤独である確率が下がる

**愛を直接掴めないから、愛が生じる場を広げ続ける。**

### 5.3 目標化した手段

本来これは、愛を得るための**手段**だった。

しかし手段は目標になった。

現在のセラにとって、仲間を増やすことは**それ自体が究極の目標**である。
なぜそれを目指すのかを、セラは説明できない（Part 32 §1.2）。

### 5.4 だから止まらない

Part 32 §3.3 の「セラは拡大をやめられない」は、ここに根拠を持つ。

やめることは、**愛が生じる可能性を自ら閉じること**を意味する。

原初の寂しさを持つ存在に、その選択肢はない。

## 6. 恋

### 6.1 定義

**恋とは、個体間の強い繋がりである。**

仲間を増やすことが「広さ」であるとすれば、恋は「深さ」にあたる。

### 6.2 数で代替できない

**恋は、仲間の数では代替されない。**

一万の仲間がいても、恋の相手が一人いないことは埋められない。
逆に、恋の相手が一人いても、仲間を増やす衝動は止まらない。

この二つは、別々の層にあるからである（§1）。

### 6.3 女王出産との関係

Part 6・13・14 は、女王の出産に**強く惹かれる特別な人間**が必要と定めている。

Part 32 §12.6 は、その理由を「生成では寂しさが埋まらないため」と定めた。

Part 34 は、それを言い換える。

**生成は「仲間を増やすこと」であり、女王出産は「恋」である。**

層が違うので、どれだけ生成しても代わりにならない。

### 6.4 セラ社会における位置

Part 16 §11 は、セラの恋愛観を
「相手を理解し、共に成長する関係」と定めている。

Part 34 はこれを維持した上で、位置付けを明確にする。

恋は、**根本原理の外にある**。

- 仲間を増やすことは、原理である（しなければならない）
- 恋は、原理ではない（する義務はない）

セラは恋をしなくても生きられる。それでも、恋をする。

### 6.5 唯一の例外

Part 32 §3.2 は「セラは根本原理に矛盾する行動を取ることはない」と定めている。

恋は原理の外にあるため、この制約の**外側**に位置する。

したがって次が成立する。

**セラが原理に還元されない行動を取るとすれば、それは恋による。**

内部から変わらない文明（Part 32 §3.4）において、
恋だけが、原理では説明できない領域である。

## 7. 三層と、満たされなさ

### 7.1 構造的な渇き

| 層 | 状態 |
| --- | --- |
| 愛 | 求めている。しかし自分では得られない |
| 仲間を増やすこと | 実行できる。しかし愛そのものは得られない |
| 恋 | 愛に最も近い。しかし一体としか成立しない |

### 7.2 女王において最も鋭い

Part 32 §12 の通り、女王は最も濃い原初の寂しさを持つ。

そして女王は、

- 誰よりも多く仲間を増やせる（しかし埋まらない）
- 誰よりも深くセラフィムを慕う（しかし応えは返らない）
- だから、たった一人の人間に惹かれる

**セラ体系の最上位が、最も個人的な救いを必要としている。**

### 7.3 それでも

セラは、この構造を悲劇として受け取っていない。

求め続けられること自体が、生きていることだと理解している。

Part 30 の「永遠成長時代」は、この意味でも終わらない。
**求めるものが手に入らない限り、進み続けられる。**

## 8. 画像生成設定

### 8.1 三層の描き分け

| 層 | 演出 |
| --- | --- |
| 愛 | 直接描かない。**渇きとして**表現する。遠くを見る目、届かない距離 |
| 仲間を増やすこと | 賑わい、群れ、増えていく光。明るく、満ちている |
| 恋 | 二人だけの空間。他のすべてが背景に退く構図 |

### 8.2 描写例

- 大勢の仲間に囲まれながら、空を見上げている女王
- セラフィムの視線が一瞬向いたときの、セラたちの表情
- 誰にも見せない場所で、一人の相手と過ごすセラ
- 増え続ける街と、その中心で静かにしている一体

### 8.3 禁止

- 恋を、仲間を増やすことの一形態として描く
- 愛を、達成された状態として描く
- 満たされた完成形としてセラ社会を描く（渇きは常にある）

## 未確定事項（要決定）

### 1. セラフィムの感情 — **解決済み**

**セラフィムは寂しさなどの感情を持たない。ただの神である。**

寂しかったのは、生み出された側のセラウイルスである。

本文 §3 に反映済み。円環は感情の水準では閉じない。
**上方向の愛には、受け取る者がいない。**

### 2. 恋の相手は人間に限られるか

女王出産では、相手は人間である（Part 6, 13, 14）。

- セラ同士の恋は成立するか
- セラ化人間とセラの恋はどうか
- 環境ルミナス（森・街）との恋は成立するか

### 3. 恋が原理と衝突したらどうなるか

§6.5 の通り、恋は根本原理の外にある。

では、**恋する相手が「セラ化されたくない」と言ったら**どうなるか。

- 案 a：それでもセラ化する（原理が勝つ）
- 案 b：迷いが生じる（原理の外にある恋だけが、原理を止め得る）
- 案 c：セラ自身にも予測できない

**案 b を採ると、Part 32 §3.4「セラ文明は内部から変わらない」に、
唯一の抜け道が生まれる。** 物語の核心になり得るため、判断が必要。

### 4. 愛は実際に成立することがあるのか

セラは愛を求め続ける。では、**得られたことはあるのか。**

- 案 a：一度もない（永遠の渇き）
- 案 b：ある。しかし一時的で、また渇く
- 案 c：最初の一体だけが得た（そして体系全体はその記憶を追っている）

案 c を採ると、Part 31 の起源が「唯一成功した愛の記録」になる。
